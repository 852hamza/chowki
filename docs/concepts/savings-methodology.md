Chowki reports what each request cost and what it saved, in the `x-chowki-cost-usd` header, the
dashboard, `chowki usage`, the admin API and the metrics. This page explains how it computes both,
so that you can check the numbers against your providers' bills. The rule throughout: a number
that Chowki can't compute from official prices is reported as unknown, never guessed.

## Cost

Chowki computes a request's cost from the tokens that the provider reports in its answer, and the
prices in its model catalog, `catalog/models.json`. Each catalog entry names the official pricing
page that its prices come from, and the date they were checked. Prices are in US dollars per
million tokens.

- **Tokens.** Input counts every prompt token, including those read from or written to the
  provider's prompt cache. Output counts every generated token, including reasoning: OpenAI and
  Anthropic count reasoning in their output tokens, and Chowki adds Gemini's `thoughtsTokenCount`,
  which Gemini reports apart.
- **Tiers.** Some models cost more above a prompt size, such as 272,000 or 200,000 input tokens.
  Chowki uses the highest tier whose threshold the request's input tokens exceed.
- **Price changes** that a provider announces carry their date in the catalog, and a request is
  priced by the prices of its day, in UTC.
- **Free tiers.** A provider marked `free_tier: true`, such as a Gemini key on the free tier, costs
  $0.

The formulas, where each product is divided by 1,000,000:

| API | Cost |
|---|---|
| OpenAI and compatible | uncached input × input price + cache reads × cache read price + cache writes × cache write price + output × output price. Without a cache write price, cache writes cost the input price. |
| Anthropic | uncached input × input price + 5-minute cache writes × cache write price + 1-hour cache writes × 1-hour cache write price + cache reads × cache read price + output × output price |
| Gemini | uncached input × input price + cached tokens × cache read price + (output + thoughts) × output price |

### Unpriced requests

Chowki records a request as unpriced, with no cost, rather than a wrong one, when:

- the model isn't in the catalog, as for local models and most OpenAI-compatible providers;
- the provider reported no usage;
- the answer names a price that the catalog doesn't model yet: an OpenAI service tier other than
  `default`, an Anthropic service tier other than `standard`, Anthropic's US-only inference or fast
  mode, a Gemini service tier other than the standard one, Gemini audio input, or Gemini's
  built-in tools.

Unpriced requests count as $0 toward budgets, and the dashboard and `chowki usage` count them, so
that you can see how much of the traffic has no price.

## Savings

Chowki counts two kinds of savings, and nothing else.

**Provider prompt caching** (`prompt_cache`). Providers charge less for prompt tokens read from
their cache, and some charge more to write them. The saving is net: what the cache reads saved,
minus what the cache writes cost above the normal input price.

    savings = cache reads × (input price − cache read price)
              − (cost of cache writes − cache writes × input price)

A request that only writes to the cache has a negative saving, which a later read makes up for.
The saving counts whether the application or Chowki marked the prompt for caching: OpenAI and
Gemini cache prompts on their own, and Chowki marks repeated prefixes for Anthropic when
`defaults.prompt_cache` is `auto`.

**The exact cache** (`exact_cache`). An answer from Chowki's exact cache costs nothing, and saves
what the original request cost. When the original was unpriced, the saving is $0.

**Everything else saves $0**, even when it may reduce your bill: requests that a budget, a rate
limit or redaction stopped, fallback to another model, and routing an alias to a cheaper model.

## Where the numbers appear

- Each answer carries its cost in `x-chowki-cost-usd`, when it's priced.
- Each request's record holds its cost, its savings and their method.
- The dashboard, `chowki usage` and the admin API sum them by day, key and model.
- `chowki_cost_usd_total` and `chowki_savings_usd` expose them as metrics; savings can be negative.

## What Chowki doesn't count

- Charges outside requests, such as Gemini's hourly storage of explicit context caches, and taxes.
- Discounts that you negotiated with a provider: the catalog holds list prices.
- Prices after the catalog's check dates: a newer Chowki carries newer prices, and `chowki doctor`
  warns when the catalog's prices are more than 90 days old.
